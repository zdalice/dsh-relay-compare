# 渠道费用对比 / Relay cost compare

## 它做什么

同一个模型,官方是按 token 卖的,中转站也是按 token 卖的——只是单价不同。这个插件把**每一次模型调用**的 token 用量同时按两套价格算一遍:

- **官方峰谷价**:DeepSeek 官方现行峰谷定价,工作日 09:00–12:00 与 14:00–18:00(北京时间)为高峰,其余时间(含周末与法定节假日)为空闲,空闲价 = 高峰价的一半;
- **中转站价**:从中转站自己公开的接口读取(`/api/prices` 模型表价,以及 `/api/platform_price/public` 的平台政策价与官方参照价)。

输入框下方会显示一条实时结论,例如「渠道费用对比 · 官方 ¥0.0119 · 中转站 ¥0.0061 · 省 ¥0.0058 (49%)」;点开是一张表,按**本会话 / 今日 / 累计**三行给出:官方高峰价、官方空闲价、中转站价、相对高峰的差额、相对空闲的差额,并列出用过的模型及其单价对照(官方参照价、中转站表价、中转站政策价)。

差额列用词随正负变化:**为正显示「省」,为负显示「多付」**;官方与中转站任一侧缺价时显示「—」,不计入差额——缺对照价的调用会在面板里单独列出。

常驻结论按**当前档位**比:高峰时段对官方高峰价,空闲时段对官方空闲价,所以它在任何时刻都反映当时真实的省钱/多花钱。

正因为官方有峰谷两档、中转站通常只有一档,所以「省了多少」必须分两种口径看:对官方高峰价省的多,对官方空闲价可能只是持平。

## 数据来源

| 数据 | 来源 |
| --- | --- |
| 每次调用的 token 用量(输入/缓存读取/缓存写入/输出/推理) | 宿主 `llm/stream` 瀑布的 `usage` 块,实时捕获,不写会话日志 |
| 官方 DeepSeek 价目 | 插件内置(人民币 / 百万 token),峰谷两档 |
| 非 DeepSeek 模型的官方参照价 | 中转站公开接口返回的官方价 |
| 中转站价 | 中转站公开的 `/api/prices` 与 `/api/platform_price/public` |
| 峰谷时段判定 | 北京时间,周末与设置中的节假日按空闲计价 |

价格默认每 30 分钟自动同步一次,也可以在面板里点「刷新价格」立即同步。

## 设置

在展开的面板里「设置」区可以改:

- **中转站地址**:默认 `https://www.cxts.top`;
- **渠道 ID**:DSH 里走中转站的 provider id(默认 `cxts`,支持逗号分隔多个);
- **价格来源**:平台政策价(默认,含折扣)或模型表价;
- **节假日**:`YYYY-MM-DD` 列表,逗号分隔;这些日期按官方空闲价计算。

设置保存在 `$DSH_HOME/storages/relay-compare/state.json`(未设置 `DSH_HOME` 时用 `~/.dsh`),与账本、会话记录一样属于本机数据。

## 已知限制

- 官方峰谷只影响 **API 单价**;订阅套餐、包月、免费额度不适用这套价格。
- 官方节假日表需要自行维护:插件不会自动联网抓取法定节假日日期。
- 中转站价格以对方公开接口为准;接口改版或该模型未公开价格时,这一项会显示为空(不计入「省了多少」)。
- 中转站可能对不同用户组给不同折扣,面板显示的是接口公开的当前政策价;接口口径与实际扣费不一致时,以中转站账单为准。
- 若模型名与中转站目录不一致,需要在中转站侧或插件设置里做映射;未映射的模型只统计官方价。
- 「本会话」统计从宿主进程启动开始累计该会话的调用,并对最近 300 个会话保留历史;不做会话日志重放,因此重装或长时间离线期间的费用不会补算。
