# dsh-relay-compare · 渠道费用对比

DeepSeek Harness 插件：把每一次模型调用的 token 用量**同时**按 DeepSeek 官方峰谷价和第三方中转站的公开销售价算一遍，在输入框下方实时显示「用中转站省了多少钱」。

同一个模型，官方按 token 卖，中转站也按 token 卖，只是单价不同。这个插件把两边的账都摆出来——包括一个容易被忽略的事实：**中转站的折扣是相对官方高峰价给的，而官方空闲价本身就是高峰价的五折**，所以在晚上、周末这类空闲时段，中转站并不一定更便宜。

## 功能

- **输入框下方常驻一条对比**：`官方 ¥1.72 · 中转站 ¥0.86 · 省 ¥0.86 (50%)`，并标注当前处于官方高峰还是空闲时段。
- **点开是浮层明细**：本会话 / 今日 / 累计三行 × 官方高峰价、官方空闲价、中转站价、对高峰差额、对空闲差额。差额为正显示「省」，为负显示「多付」，任一侧缺价显示「—」且不计入差额。
- **按当前档位比较**：高峰时段对官方高峰价，空闲时段对官方空闲价，常驻数字在任何时刻都反映当时真实的省/多花。
- **单价明细**：用过的模型逐一列出官方参照价、中转站表价、中转站政策价。
- **自动同步**：默认每 30 分钟拉取一次中转站价目，也可手动刷新；同步失败或价格过期会在 chip 上打 ⚠。

## 安装

从 GitHub（源码安装）：

```sh
dsh plugin --profile desktop add github:GH_OWNER/dsh-relay-compare
```

或从 npm（预构建，免构建授权）：

```sh
dsh plugin --profile desktop add dsh-relay-compare
```

装完重启 harness。入口在**输入框下方**（和"对话费用"那条挨着），也可在 **设置 → 插件** 里看到 `dsh-relay-compare` 这一行。

## 数据来源

| 数据 | 来源 |
| --- | --- |
| 每次调用的 token 用量 | 宿主 `llm/stream` 瀑布的 `usage` 块，实时捕获，不写会话日志 |
| 官方 DeepSeek 价目 | 插件内置（人民币 / 百万 token），高峰与空闲两档 |
| 非 DeepSeek 模型的官方参照价 | 中转站公开接口里的 `official` 字段 |
| 中转站表价 | `GET {中转站}/api/prices` |
| 中转站政策价 | `GET {中转站}/api/platform_price/public` |
| 峰谷判定 | 北京时间，工作日 09:00–12:00 与 14:00–18:00 为高峰，周末与设置中的节假日按空闲计 |

两个中转站价目口径都取自对方**公开、无需登录**的接口：表价给 `input` / `output`（元 / 百万 token），缓存命中价由 `input × extra_ratios.cached_tokens` 换算；政策价直接给三项单价并附 `discount`。插件默认用政策价，可在面板里切到表价，两个价也并排显示，不隐藏任何一个。

## 设置

展开面板底部的「设置」区可以改：中转站地址、渠道 ID（DSH 里走中转站的 provider id）、价格来源（政策价 / 表价）、自动同步间隔、节假日日期。设置保存在 `$DSH_HOME/storages/relay-compare/state.json`（未设置 `DSH_HOME` 时为 `~/.dsh`）。

## 已知限制

- 官方峰谷只影响 **API token 单价**；订阅套餐、包月、免费额度不适用这套价格。
- 官方节假日表需要自行维护，插件不会联网抓取法定节假日。
- 中转站价目以其公开接口为准；接口改版或该模型未公开价格时该项显示为空，且**不计入**差额（不会把缺失价格当成 0）。
- 中转站可能对不同用户组给不同折扣；接口口径与实际扣费不一致时，以你的账单为准——这时切换「价格来源」即可。
- 模型名与中转站目录不一致时需要映射；未映射的模型只统计官方价。
- 「本会话」从宿主进程启动开始累计，并对最近 300 个会话保留历史；不做会话日志重放，重装或长期离线期间的费用不会补算。

## 目录结构

```
index.js           宿主半边：包裹 llm/stream 采集用量、拉取并缓存价目、暴露面板接口
client.js          客户端半边：注册到 conversation.composer.dock 的 chip 与浮层明细
cordis.patch.yml   bundle patch：插入 relay-compare 这一行
locale/            插件管理器显示用文案（zh / en）
docs/DETAIL.md     详情文档：口径、来源、限制
icon.svg           插件图标
```

## 开发

插件没有构建步骤，`client.js` 直接就是模块加载器要求的形态。改完用宿主自带的 Node 做语法检查：

```sh
node --check index.js && node --check client.js
```

状态文件与账本一样属于本机数据，不随插件升级覆盖。
